# Piano Notation

Бесплатное приложение на Flutter: виртуальное пианино, которое слушает, что
вы играете, и превращает это в ноты на нотном стане — с экспортом в PDF.
Делается для детской музыкальной школы, без рекламы и платных функций.

Это не очередной клон виртуального пианино — главное здесь именно
**генерация нотной записи** из реальной игры: сыграл мелодию → получил
готовые ноты на стане, которые можно распечатать.

## Возможности

- Виртуальная клавиатура на 88 клавиш (A0–C8) с подписанными нотами,
  глиссандо (проведи пальцем — играет каждая клавиша под ним) и поддержкой
  аккордов (несколько пальцев одновременно)
- Полоска-навигатор сверху клавиатуры — уменьшенная схема всей клавиатуры с
  окном текущей видимой области, тап или протягивание сразу листает
  клавиатуру; рядом кнопки +/- меняют размер клавиш
- Запись игры → автоматическая квантизация в стандартные длительности
  (шестнадцатые…целые), живое обновление нот прямо во время записи
- Гранд-стан фортепиано (скрипичный + басовый ключ, как в настоящих нотах):
  ноты распределяются по регистру, восьмые/шестнадцатые группируются в общие
  лиги, а очень высокие/низкие ноты — под знаком 8va/15ma вместо кучи
  добавочных линеек
- Настраиваемый темп (BPM) — квантизация подстраивается под то, как реально
  играли
- Режим «играть по нотам»: PDF, экспортированный приложением, несёт внутри
  себя саму запись — открой его снова и приложение подсветит клавиши
  (тренажёр ждёт нужную клавишу, или автоигра проигрывает пьесу сама)
- Три стиля звука на настоящих сэмплах (не синтез): концертное пианино,
  электропиано, синтезатор — см. раздел «Благодарности»
- Педаль сустейна
- Экспорт нот в PDF (с поддержкой кириллицы и узбекской латиницы)
- Языки интерфейса: русский, узбекский, английский
- Светлая/тёмная тема

## Структура кода

- `lib/example_usage.dart` — основной экран (клавиатура, запись, нотный стан, PDF)
- `lib/piano_keyboard.dart` — виртуальная клавиатура, мини-навигатор, зум
- `lib/piano_sound.dart`, `lib/piano_sample_map.dart` — проигрывание сэмплов,
  управление активными нотами (демпфер, педаль)
- `lib/quantizer.dart` — квантизация сырых нажатий в тактовую сетку (4/4)
- `lib/staff_position.dart`, `lib/staff_painter.dart` — позиции нот на стане
  и их отрисовка (`CustomPainter`)
- `lib/pdf_export.dart` — рендер нотного стана в PDF
- `lib/notation_state.dart`, `lib/app_settings.dart` — состояние приложения
  и настроек (Riverpod)
- `lib/settings_drawer.dart`, `lib/translations.dart` — панель настроек и
  локализация
- `third_party/audioplayers_android_patched/` — локальный патч
  `audioplayers_android`: включает питч-шифт сэмплов через `SoundPool`
  вместо `MediaPlayer` (надёжнее и быстрее при частой игре, см. код для
  подробностей)

## Запуск

```bash
flutter pub get
flutter run
```

Приложение фиксирует альбомную ориентацию (клавиатура широкая).

## Известные ограничения

- Аккорды поддерживаются, но без разбора на отдельные голоса/партии — всё
  записывается в один поток событий, ноты попадают на скрипичный/басовый
  стан по высоте, а не по тому, какой рукой реально играли
- Только диезы, без выбора тональности/бемолей
- Паузы — упрощённые векторные глифы, не полноценная гравировка
